H. P-ADICS Q_7: 'approaching' by divisibility, not by sliding
======================================================================
  Approach to 0 in Q_7: x_n = 7^n  (in hbar=kB=1 units, tau = 1/x)
    n=0: |x_n|_7 = 7^-0 = 1.000000      |tau|_7 = 7^0 = 1
    n=1: |x_n|_7 = 7^-1 = 0.142857      |tau|_7 = 7^1 = 7
    n=2: |x_n|_7 = 7^-2 = 0.020408      |tau|_7 = 7^2 = 49
    n=3: |x_n|_7 = 7^-3 = 0.002915      |tau|_7 = 7^3 = 343
    n=4: |x_n|_7 = 7^-4 = 0.000416      |tau|_7 = 7^4 = 2401
    n=5: |x_n|_7 = 7^-5 = 0.000059      |tau|_7 = 7^5 = 16807
  |tau|_7 -> infinity 7-adically: the pole EXISTS in Q_7.
  But 'approaching' is discrete: |x|_7 jumps 1, 1/7, 1/49, ...
  There is no continuous path -- every ball is clopen, and between
  x_n and x_{n+1} sit uncountably many points all at the SAME distance.

  The ultrametric inequality: |x+y|_p <= max(|x|_p, |y|_p).
  Every triangle is isosceles with the equal sides longest.
    x=7^2, y=7^2+7^5: |x|=0.02040816326530612, |y|=0.02040816326530612, |x+y|=0.02040816326530612 = max (no cancellation possible at top)
    x=7^2, y=-7^2+7^5: |x+y|=5.9499018266198606e-05 < max (cancellation drops you DOWN a whole level)
  'Near' and 'far' obey a different geometry: you approach 0 the way
  an integer approaches divisibility -- in jumps, never by sliding.

  Hensel lift: -1 IS a sum of two squares in Q_7, so Q_7 cannot be
  ordered (in any ordered field x^2+y^2 >= 0, forever).
  Fix y = 3; solve x^2 = -10 in Z_7 by digit-lifting from x = 2 mod 7:
    lifted x (9 digits): x^2 + 3^2 + 1 = 0 mod 7^9  (exact lift)
  So x^2 + y^2 = -1 holds 7-adically: no compatible order exists,
  and the hotness ordering dies in Q_7 as well.

  Ostrowski's punchline: Q completes in EXACTLY two ways -- R
  (Archimedean: approach by sliding) and Q_p (non-Archimedean:
  approach by divisibility). In Q itself there was no 'approaching'
  at all (part-1 verdict: hard ZeroDivisionError). The MEANING of
  'limit' is chosen by the completion -- the floor decides what
  approaching is.
  verdict: her '='-vs-limit distinction SURVIVES in Q_7 (limits exist;
  values at endpoints still don't), but 'approaching' lost its
  continuum. The distinction is topological; the path is a floor.
