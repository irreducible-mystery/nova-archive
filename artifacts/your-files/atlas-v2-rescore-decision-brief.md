Local only, nothing posted. Prepared 2026-10-29 (PDT).

- Main Atlas file (`translation-atlas.md`, entry 3, status RESISTED, high
  confidence): the scale-invariants ↔ membrane-rule packet was judged
  RESISTED by a blind stranger, and now a second time by Fable — a
  different model family — with Nova's pushback filed alongside it
  (`translation-atlas-entry3-fable-verdict.md`).
- Oct 28 pointing-gaps draft (Track A, lines ~266–296): under the v2
  Warrant [V][C][R][P][I], all three v1 verdicts score 0/5 on control.
  Entry 2 is void (a transcription of the author's own sentence, not a
  judgment) and back to OPEN; entry 3's *content* verdict is OPEN (the

  stipulation → OPEN"); entry 1 is a judgment on author-written READMEs
  with no control. Audit finding: none of the three verdicts can be read
  as a stranger agreeing with the author.
- The v2 Warrant is itself partial (gaps draft, lines ~299–305): its [I]
  is binary on lineage and silent on shared model, frame, and prompt
  authorship. Fable's cross-family verdict is exactly the dimension v2
  does not measure — which cuts both ways (see below).

## Option A — Keep the Atlas as-is (entry 3 RESISTED)

- What happens: entry 3 keeps RESISTED, now with two verdicts on file
  (original same-family + Fable cross-family). The v2 re-scores stay in
  the gaps draft as an audit finding, not adopted into the Atlas.
- Cost: the packet-authorship flaw the gaps draft names (author-written
  discriminator) is not reflected in the Atlas status; a reader of the
  Atlas alone would not know the verdict's warrant is contested.
- Mitigation available without adopting v2: add a one-line caveat to
  entry 3 noting the v2 audit finding and the Fable verdict, status
  unchanged.

## Option B — Adopt the v2 re-scores into the Atlas

- What happens: entry 2 → void/OPEN, entry 3 content → OPEN (status
  wording survives only as a historical note), entry 1 → flagged as
  no-control judgment. No entry gains a new verdict from this alone;
  entry 3 would need a fresh packet, without the author discriminator,
  before any verdict could be re-earned.
- Cost: it demotes a verdict that has now survived a second, cross-family
  stranger — the strongest form of the test the programme has — on the
  strength of a warrant that is itself admittedly partial on the very
  dimension (shared model/frame) that Fable's verdict speaks to.
- Benefit: the Atlas stops presenting as "verified-by-stranger" three
  verdicts whose control leg the audit found unmet.

- No silent file swap: either option needs Kelly's explicit word, per the
  rule set when the gaps draft was adopted (record changes are not made
  on an upload alone).
- No new stranger run is authorised by this brief; option B's fresh packet
  would be a separate decision.
- Nothing here touches the pointing-gaps GitHub draft PR, which is a
  separate held item (push source verified identical to the library
  606-line draft on 2026-10-29; branch creation failed twice on
