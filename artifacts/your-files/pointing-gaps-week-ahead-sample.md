# Pointing gaps — one filled row, one indexed card (sample, local only)

Companion to `pointing-gaps-week-ahead.md` (Sunday 2026-10-25). That draft
asked which track, if either, for the week; this file does not answer that
choice. It shows what one finished piece of each track actually looks like,
using only evidence already on the record — so the choice, if she makes one,
is about a concrete artifact, not an abstract table.

Nothing here is posted to any repo. No governance is proposed. No
consequence is filled in anywhere: the consequences column is the gap
itself, per the layer rule.

## Track A sample — Gap 5, one audit row fully filled

Pair: **stranger-breaker (A) vs /describe round-trip (B), Translation
Atlas entry 4** (filed 2026-10-24, RESISTED).

- **Shared instrument?** No. A is a fresh judge outside the author's loop;
  B is a journey across media and back (prompt → image → /describe →
  compare). Different geometries of "outside" — that is entry 4's residue
  point 1, not an assumption.
- **Shared training / model?** YES, flagged, on the stranger side. The
  entry records it honestly: the stranger was a fresh subagent of this
  chat, packet-only input, "same model family as the packet's author;
  blinded to provenance, not to style." The /describe side is a different
  model type (Midjourney), so the sharing is not across both methods —
  it is a caveat on any verdict the stranger returns.
- **Shared data / author?** No, as far as the packet goes. Packet texts
  only, no pairing labels, no Atlas context, no repeat pairing with
  entries 1–3. Provenance was blinded.
- **Shared incentive / frame?** Yes, at the framing level. Both texts
  were posed by Kelly/Nova as "what verifies," and both share the one
  theme that survives entry 4: verification is not self-certification.
- **Independence: measured or asserted?** Partially measured. What was
  blinded (provenance, pairing, context) is named; what was not (model
  family, style) is also named. That is the template the rest of the
  audit should copy.
- **What this row changes.** Entry 4 is RESISTED, so no agreement is being
  counted here — the row's value is as a standard. If a future stranger
  verdict came back CONFIRMED, this row says exactly what would still
  need to be true before counting it: a stranger from a different model
  family, with style blinded as far as that is achievable, and the same
  honest note if either condition fails. A CONFIRMED from the same
  family would be a weaker claim than the word suggests, and the row
  would say so in plain sight.

The draft's other rows stay as they were — vary-floors lenses and
breaker-vs-round-trip as a pair are still '?', not filled by assertion.
One filled row does not certify the programme; it shows the standard
the unfilled rows would have to meet.

## Track B sample — Gap 3, one Floor Card indexed

Card: **Rung-1 Association** (from `floor-cards.md`, worked example 1).

- **Name / Tell:** Rung-1 Association. Tell: predicts a randomized
  trial's outcome from observational data — and is confident about it.
- **Primitives / Native question:** Variables, joint distributions,
  conditional probabilities. "What goes with what?"
- **Who treats it as fundamental, and since when:** In Kelly's
  programme, the Assoc animal in the act-as-if series stands on this
  floor — that is the programme's use, recorded here, not a claim about
  who in the wider field treats it as fundamental. That wider "who"
  is left blank rather than invented.
- **Stranger-inspectable?** Yes, by the card's own design: it carries
  a tell and a canonical probe (`act-as-if-causal/`), so a fresh
  instance can recognize the floor and predict its blind spot without
  being told the programme's conclusions.
- **Shown constructed?** Probe-demonstrated limit, not an Atlas verdict.
  In `act-as-if-causal/`, Assoc recommends no-pill (risk 0.236) while
  the truth is do(pill) halves hospitalizations — a structural
  disagreement showing the floor's blind spot (intervention has no
  grammar here). That demonstrates a limit; it is not filed here as a
  full "shown constructed" verdict, which would need its own entry.
- **Consequences:** Left blank on purpose. Filling it would be a
  governance decision about what changes when a floor is shown
  constructed — the gap itself, not a clerk's job, and not something
  a local file can decree.
