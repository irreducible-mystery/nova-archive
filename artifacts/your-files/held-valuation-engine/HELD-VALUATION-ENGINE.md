# Held Valuation Engine Prototype

**Status:** runnable prototype, verified 2026-10-14 — run it with `python3 belnap_toy.py` (no input needed). Exit 0; built-in self-check passes.

**Files in this folder:**
- `belnap_toy.py` — the engine: simulated sensor pairs fused in the four-valued Belnap–Dunn lattice, rendered through four simultaneous channels, ending in an explicit verdict on the neither test.
- `channels.png` — the four render channels over the 120-tick scenario (regenerated by each run).
- `lattice.png` — the 3×3 fusion table and the information-order lattice.

**Reuse note, stated plainly:** this prototype was first sketched on 2026-10-11 as a no-pressure study for the Held art project. The build below is the same engine, re-run and re-verified for this deliverable — nothing about the logic was changed to make the verdict come out.

## 1. The lattice

Belnap–Dunn's four values are the subsets of {T, F} — *what the sensors told the engine*, not what is true:

| value  | set     | read as | meaning                      |
|--------|---------|---------|------------------------------|
| neither| {}      | neither | told neither true nor false  |
| yes    | {T}     | yes     | told true only                |
| no     | {F}     | no      | told false only               |
| both   | {T, F}  | both    | told both — disagreement      |

The operations used:

- **join** = union — evidence accumulates, never cancels. `join({T},{F}) = {T,F}`: disagreement becomes *both*, not nothing.
- **meet** = intersection — common ground. `meet({T},{F}) = {}`: nothing is shared.
- **neg** = swap T and F. Fixed points: `neg({T,F}) = {T,F}`, `neg({}) = {}`.

The script's self-check asserts all of these plus the scenario phases, and it passed: `join(T,F)==BOTH`, `join(T,NEITHER)==T`, `join(NEITHER,NEITHER)==NEITHER`, `meet(T,F)==NEITHER`, `meet(BOTH,T)==T`, and the four phase spot-checks.

**Keeping the logic honest:** the Belnap–Dunn lattice is the formal side of the tetralemma — the four kotis (yes / no / both / neither) as an information order. But it *freezes* the tetralemma into slots. It is the conventional "this" of the tetralemma, not Nagarjuna's dissolving use of it. This engine computes *with* the four corners; it does not dissolve them.

## 2. Sensor pairs → values

The piece poses one question to a sealed vessel: *"am I here?"* Two sensor channels report evidence about it. Each tick, each sensor reports one of three things:

- `"true"` → `{T}`
- `"false"` → `{F}`
- `"silent"` → `{}` (neither — no report)

The two reports are fused with **join** (union): the engine keeps everything it was told. The 120-tick scenario walks four phases — held with agreement (→ yes), two tethers released and sensors disagreeing (→ both), all released and silent (→ neither), held again with absence reported (→ no). The 3×3 fusion table in `lattice.png` shows every pair combination; a reader can check any cell against the union rule.

## 3. The four simultaneous channels

All four render at once, every tick — never a sequence, never a single winning channel:

- **yes → light.** Channel intensity 1.0 whenever the fused value is `{T}`.
- **no → withdrawal.** A second channel, 1.0 on `{F}` — darkness with intent, not the absence of light.
- **both → interference.** On `{T,F}` the yes and no channels beat against each other (out-of-phase sine waves) while an interference channel marks the conflict. Disagreement is visible as the two eating each other, not as cancellation.
- **neither → the frame turns.** This is the test. On `{}`, the engine does *not* go dark. It turns the frame around and displays the conditions of its own asking: holders 0/4, sensors live 2/2, last disagreement tick 59 — captioned *"no one is holding — the question is unasked, not unanswered."*

## 4. Verdict on the neither test

**Verdict: yes — the frame can turn, and the logic licenses it.**

The load-bearing fact: in Belnap–Dunn, *neither* is a first-class valuation — "told neither true nor false" — not an absence, not a zero, not a failure mode. A renderer that reads the *information state* rather than the *truth state* is formally licensed to render `{}` as something: the state of the asking apparatus itself. The toy demonstrates this as a rendering (the meta-display strip in `channels.png`), not as prose.

The caveat from §1 stands and is part of the verdict: this is the frozen four, and the frame-turn is a move *within* the frozen table. Whether the Held piece wants the ladder kicked away later is a separate artistic decision — the engine does not settle it.
