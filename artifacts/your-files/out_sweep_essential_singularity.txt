=== approach along rays: z = t * e^{i phi}, t -> 0+ ===
log|e^{1/z}| = cos(phi)/t,  arg(e^{1/z}) = -sin(phi)/t  (exact, no overflow)

phi =   0 deg:  log|w|=+10 arg=-0rad   ->   log|w|=+100 arg=-0rad   ->   log|w|=+1000 arg=-0rad
phi =  45 deg:  log|w|=+7 arg=-7rad   ->   log|w|=+71 arg=-71rad   ->   log|w|=+707 arg=-707rad
phi =  90 deg:  log|w|=+0 arg=-10rad   ->   log|w|=+0 arg=-100rad   ->   log|w|=+0 arg=-1000rad
phi = 135 deg:  log|w|=-7 arg=-7rad   ->   log|w|=-71 arg=-71rad   ->   log|w|=-707 arg=-707rad
phi = 180 deg:  log|w|=-10 arg=-0rad   ->   log|w|=-100 arg=-0rad   ->   log|w|=-1000 arg=-0rad

reading: phi=0   log|w| -> +inf  (blows to infinity);
         phi=180 log|w| -> -inf  (collapses to 0, never touching it);
         phi=90  |w|=1 forever, arg spins -1000 rad by t=0.001:
                 no limit at all -- the curve wraps the unit circle
                 infinitely often, taking every value on it.

Picard's exception: e^{1/z} != 0 for all z -- the one value the
wildest blowup never touches. Compare: the gap stays empty.
