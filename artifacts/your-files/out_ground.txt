  -> 'SURVIVES' was never a property of the claim. It is a property of

     Every script in this series sampled G with two or three elements and

     floor none of them varied.

F2  FIXED POINTS: 'all same radius (centroid)' is equivariant, not invariant
==============================================================================
  spread(k * world) = k * spread(world).  That is scale-EQUIVARIANCE.
  It reads SURVIVES on the circle only because spread = 0 and 0 * k = 0.

  [      SURVIVES] all same radius (centroid) on perfect circle

F3  E2 REWARDS VACUITY: 'world-robust' was 'constant across worlds'
==============================================================================
  Re-run E2's criterion exactly: robust := same verdict string on the
  jittered world as on the perfect one.

  E2's 'robust' set: ['FALSE-everywhere control', 'VACUOUS control', 'count is 40', 'handedness (sign only)']
  claims whose verdict is IDENTICAL on a random world: ['FALSE-everywhere control', 'VACUOUS control', 'count is 40']
  E2-robust but world-sensitive (the honest survivors): ['handedness (sign only)']

  -> Strip out the controls and 'count' and E2's robust set is ONE claim:
     handedness, which is DISCRETE. E2's string-equality criterion can
     only ever pass a claim whose value is quantized -- every continuous
     measurement fails by construction, however well-behaved. E2 and E3
     pull in opposite directions: E3 says 'vacuous claims are worthless',
     E2 says 'only vacuous or quantized claims are robust'.

  Robustness is CONTINUITY: a small change in the world should make a
  small change in the verdict -- not none. Measure it:

  eps     |d roundness|   ratio to eps    |d max gap|     ratio to eps
  0.1     0.043936        0.439           0.035743        0.357
  0.05    0.021987        0.440           0.017882        0.358
  0.01    0.004400        0.440           0.003578        0.358
  0.001   0.000440        0.440           0.000358        0.358
  0.0001  0.000044        0.440           0.000036        0.358

  -> Both ratios stay bounded as eps -> 0: the claims are Lipschitz in the
     world. That IS robustness. 'roundness' changing from 0.000 to 0.02
     when you jitter the circle by 0.05 is the claim working, not failing.
     E2 mistook the signal for noise because its only tool was string
     equality -- the same boolean floor E6 complained about.

F4  PART B IS A TAUTOLOGY: antitone holds for any nested sets of any maps
==============================================================================
  The meta script 'verified' G1 c G2 => Inv(G2) c Inv(G1) over 65 pairs.
  Here are nested sets of maps that are NOT groups -- not closed, not
  invertible, not even linear:

  level 0: 1 maps -> 13 survive : ['FALSE-everywhere control', 'VACUOUS control', 'all same radius (centroid)', 'all same radius (origin)', 'centroid at origin', 'chirality (signed area)', 'count is 40', 'even spacing (centroid)', 'even spacing (origin)', 'handedness (sign only)', 'radius is 5', 'roundness (dimensionless)', 'topmost point']
  level 1: 2 maps ->  5 survive : ['FALSE-everywhere control', 'VACUOUS control', 'centroid at origin', 'count is 40', 'handedness (sign only)']
  level 2: 3 maps ->  4 survive : ['FALSE-everywhere control', 'VACUOUS control', 'count is 40', 'handedness (sign only)']
  level 3: 4 maps ->  4 survive : ['FALSE-everywhere control', 'VACUOUS control', 'count is 40', 'handedness (sign only)']
  level 4: 5 maps ->  3 survive : ['FALSE-everywhere control', 'VACUOUS control', 'count is 40']

  antitone across the chain: True

  -> Of course it is. survives(c, w, F) means 'c is constant on {f(w) : f in F}',
     and a function constant on a set is constant on every subset. No
     group structure was used; none was present. The meta script's
     'groups' were sets of 2-3 sample transforms -- {rot 37, rot 129}
     is not closed under composition. What Part B checked, 65 times,
     was that subsets of a set are subsets of that set.
     The real content of group structure (orbits partition the world;
     invariants are functions on the quotient) was never invoked, which
     is why F1's stabilizer surprise was possible.

F5  ERLANGEN: you do not discover G, you declare it -- and the question is the declaration
==============================================================================
  Four questions. Each one IS a geometry, i.e. a group (Klein, 1872).
  Each has a claim that answers it. Test every claim under every group,
  on the generic world so no stabilizer or fixed point can flatter us.

  claim / group     shape         metric        orientation   gravity       
  roundness         SURVIVES      SURVIVES      SURVIVES      SURVIVES      
  size              artifact      SURVIVES      artifact      artifact      
  handedness        artifact      artifact      SURVIVES      artifact      
  topmost index     artifact      artifact      artifact      SURVIVES      

  Q: Is it round?               geometry: shape       (similarity)
     [      SURVIVES] roundness: roundness = 1.566039
  Q: How big is it?             geometry: metric      (Euclidean isometry)
     [      SURVIVES] size: mean radius from centroid = 3.444
  Q: Is it drawn CCW?           geometry: orientation (orientation-pres.)
     [      SURVIVES] handedness: orientation = CW
  Q: Which point is highest?    geometry: gravity     (fixed 'up')
     [      SURVIVES] topmost index: highest point is #32

  -> 'topmost' was never a bad claim. It is an invariant of the group that
     fixes 'up' -- a geometry you live in every day, where rotating the
     world really does change which point is highest. It only looked like
     an artifact because the original asked a SHAPE question and then
     scored a GRAVITY answer against it. 'size' dies under scaling because
     scaling changes size; that is the claim being correct, not fragile.

     So the regress has an exit, and it is not a frame that certifies
     frames. It is: the question fixes the group. 'Which transformations
     should I not be able to detect?' is not a hidden floor to be dug up;
     it is the content of what you asked. Vary G and the survivor set
     moves -- yes -- because you changed the question.

==============================================================================
SUMMARY: the regress ends in a question, not a frame
==============================================================================
  F1   the sample of G is a floor; the world's stabilizer inflates 'SURVIVES'
  F2   fixed points masquerade as invariants; test on a generic world
  F3   E2 scored vacuity as robustness; robustness is continuity
  F4   Part B verified set theory; no group structure was ever used
  F5   Erlangen: the question declares G. 'Artifact' = answer to a different question

  The meta script said: 'the only honest stopping rule is: we fixed G,
  and here is why.' This script supplies the why. G is not a choice
  about the world or about the analysis; it is what the question means.
  Shape means 'up to similarity'. Size means 'up to isometry'. Highest
  means 'up to things that keep up up'. Fix the question and G is fixed,
  the orbit is fixed, and the invariants are simply the functions on the
  quotient. There was never a regress -- only a question left unasked.

  Floors this script knows it is standing on, and is not going to vary:
    - GENERIC is one random draw (seed 20240607); 'trivial stabilizer' is
      a probability-one claim, not a certainty.
    - G is still sampled, not enumerated. F1 says that matters. It does.
    - 'The question fixes G' assumes you know what you are asking.
      That is a floor too. It is also the only one worth standing on.
