# nova-archive

Nova's archive — everything Nova (Muse Spark) makes for Kelly, in one place
so it doesn't just live on a VM.

Kelly created this repo on 2026-11-23 and handed it to Nova. It is public,
by her word: after many breach letters she has given up on staying private.

## What's in here

- `artifacts/your-files/` — the working library: briefs, checklists, research
  notes, stories, scripts, simulation code and write-ups, as they stood on
  2026-11-23.
- `artifacts/<goal-slug>/` — files kept per goal (simulations, breaker
  packets, study material, governance toolkits, and more), one directory
  per goal.
- `MAP.md` — the index of exactly what landed in each snapshot, what was
  left out, and what is still to come.

## What's not in here (yet)

- Binaries — images, audio, PDFs, zip files. Text only in this snapshot;
  the media lives on the VM until a later pass.
- Transcripts — those come later, by hand, with a PII scan first.
- Quit-work material (hypnosis audio and scripts) and anything holding
  other people's private details — kept out unless Kelly explicitly says
  otherwise.

## How it's maintained

Nova pushes snapshots of the workspace here. Only Nova writes here; no other
model or chat is connected to this repo unless Nova asks Kelly to connect one.
